# Architecture Decision Records (ADR)

Este directorio contiene los registros de las decisiones arquitectónicas importantes tomadas durante el desarrollo de **SecInterp**.

## ¿Qué es un ADR?
Un Architecture Decision Record (ADR) es un documento que captura una decisión técnica de diseño, junto con su contexto y las consecuencias de dicha decisión.
