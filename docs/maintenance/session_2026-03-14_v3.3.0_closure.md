## Technical Lessons Learned
1. **Mocking Precedence**: In QGIS-agnostic tests, `BaseTestCase` (or any module performing `qgis` mocking) MUST be imported before any `qgis.core` or `qgis.gui` imports to avoid `ModuleNotFoundError` during test collection.
2. **GeoPackage vs Shapefile**: GeoPackage is significantly better for 3D geological data as it handles Z-coordinates natively without the 10-character attribute limit of DBF.
3. **DXF Integration**: QGIS provides `QgsDxfExport` which is powerful enough to handle 3D geological sections without requiring external dependencies like `ezdxf`.
