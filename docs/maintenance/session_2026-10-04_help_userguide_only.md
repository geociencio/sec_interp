## Technical Summary

The plugin's **Help** button (`gui/main_dialog.py::open_help`) opens
`help/html/<locale>/index.html`. The offline manual is generated by
`scripts/build_docs.sh` from the Sphinx sources in `docs/source/` and previously
shipped multiple documents (`index`, `USER_GUIDE`, `TECHNICAL_COMPENDIUM`). Because
the build already pruned the developer/API pages, `USER_GUIDE.html`'s sidebar kept
**dead links** to the removed documents.

This session makes the offline manual contain **only the User Guide**, with a clean
navigation, **without touching the published website** and **without changing the
plugin code** (the Help button keeps opening `index.html`).

As a side exploration, **graphify** (a code knowledge-graph CLI) was evaluated: a
code-only graph of the plugin was generated under `graphify-out/` (now git-ignored).

## Changes Made

### Offline help — User Guide only (`92e5eabd`)
- **`docs/source/help_index.rst`** (new): master document for the offline manual whose
  toctree references **only** `USER_GUIDE`.
- **`docs/source/conf.py`**: when `SECINTERP_DOCS_HELP=1`, `exclude_patterns` lists every
  source document except `help_index`/`USER_GUIDE`; in website mode it excludes
  `help_index.rst` so the orphan page never appears on the published site.
- **`scripts/build_docs.sh`**: split the build into **web** (`index.rst`, full set) and
  **help** (`root_doc=help_index`, `SECINTERP_DOCS_HELP=1`) passes; after copying, rename
  `help_index.html` → `index.html` and patch the `help_index.html` links so the Help button
  keeps working unchanged. Removed the now-obsolete developer-docs prune block.

### Repository hygiene (`81d1f39d`)
- **`.gitignore`**: ignore `graphify-out/` (local code graph + Obsidian vault).

### graphify (evaluation, not committed)
- `graphify extract . --code-only` over the plugin code (tests/scripts/docs/i18n/resources
  excluded): **192 files, 2929 nodes, 5216 edges, 178 communities**.
- `graphify benchmark`: **13.7× fewer tokens per query**; Obsidian vault export produced
  3107 notes under the ignored `graphify-out/obsidian/`.
