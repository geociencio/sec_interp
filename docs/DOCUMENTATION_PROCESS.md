# Documentation Generation Process

> How SecInterp's documentation is built, translated and published.
> See also [DOCS_INDEX.md](DOCS_INDEX.md), [DOCS_STYLE_GUIDE.md](DOCS_STYLE_GUIDE.md)
> and [USER_GUIDE_CONVENTIONS.md](USER_GUIDE_CONVENTIONS.md).

## Overview

Documentation is authored in **MyST Markdown** under `docs/source/` and built with
**Sphinx** into static HTML for several languages. The website is published to a
**separate repository** (`sec_interp_docs`) that serves GitHub Pages; an optimized
copy is bundled with the plugin as its **offline help** (`help/html/`).

## Prerequisites

- `uv` (Python environment) with the dev group (`sphinx`, `sphinx-rtd-theme`,
  `sphinxcontrib-mermaid`, `myst-parser`, `sphinx-intl`).
- System `gettext` (`msgfmt`) for compiling `.po` catalogs.

```bash
uv sync
# Debian/Ubuntu: sudo apt-get install -y gettext
```

## Components

| Component | Path | Notes |
|-----------|------|-------|
| Sources | `docs/source/*.md` | MyST; includes `USER_GUIDE`, `ARCHITECTURE`, `DEVELOPMENT_GUIDE`, `TECHNICAL_COMPENDIUM`, `CORE_DISTINCTION_GUIDE*`, `MAINTENANCE_LOG` |
| API stubs | `docs/source/sec_interp*.rst` | Generated by `sphinx-apidoc` (one page per module) |
| Images | `docs/source/images/` | See [USER_GUIDE_CONVENTIONS.md](USER_GUIDE_CONVENTIONS.md) |
| Translations | `docs/locales/<lang>/LC_MESSAGES/*.po` | User-facing catalogs only (`.mo` are generated) |
| Sphinx config | `docs/source/conf.py` | Version auto-read from `metadata.txt` |
| Build script | `scripts/build_docs.sh` | Full pipeline |
| Tooling | `scripts/check_docs.py`, `scripts/sync_docs_version.py`, `scripts/docs_i18n_status.py`, `scripts/i18n/translate_docs.py` | Gates and helpers |

## Pipeline (`scripts/build_docs.sh`)

Run with `make docs` (or `./scripts/build_docs.sh [OUTPUT_DIR]`; default `../sec_interp_docs`).

1. **Clean** `docs/build/`.
2. **Generate API stubs** — `sphinx-apidoc -o docs/source . docs/ tests/ scripts/ help/ build/ --force --separate --module-first` → one autodoc page per plugin module (excludes `tests/`, `scripts/`, `docs/`, `help/`, `build/`).
3. **Sync version headers** — `scripts/sync_docs_version.py` (reads `metadata.txt`).
4. **Compile catalogs** — `scripts/i18n/translate_docs.py compile` (`.po` → `.mo`).
5. **Build HTML** for the union of the two locale sets (parallel, `-j auto`).
6. **Publish** the `WEB_LOCALES` into `$OUTPUT_DIR/<lang>/`.
7. **Offline help** — sync `HELP_LOCALES` into `help/html/<lang>`, dedupe images, strip search/API/sources/fonts.
8. **Deploy** — if `$OUTPUT_DIR/.git` exists, commit (`docs: auto-build from sec_interp@<hash>`) and `git push origin main`.

### Locale sets

| Set | Variable | Default | Controls |
|-----|----------|---------|----------|
| Published website | `DOCS_LOCALES` | `en es` | What is pushed to `sec_interp_docs` |
| Offline help | `DOCS_HELP_LOCALES` | all UI languages | The in-plugin manual |

**Policy:** a language joins the published website only when its `USER_GUIDE.po`
reaches **≥ 80%** coverage (`make docs-i18n`).

## Commands

| Command | Purpose |
|---------|---------|
| `make docs` | Build + export + (if a git repo) publish |
| `make docs-check` | Fail on stale module refs, broken links, mirror drift |
| `make docs-version` | Sync version/date headers from `metadata.txt` |
| `make docs-i18n` | Coverage report (`--min N` to enforce) |
| `make docs-i18n-update` | Extract `.pot` + `sphinx-intl update` (user-facing catalogs) |
| `bash scripts/sync_docs_mirrors.sh [--check]` | `docs/` ↔ `docs/source/` mirrors |
| `bash scripts/sync_vault_mirrors.sh [--check]` | Obsidian vault mirrors |

## Translation workflow

```bash
make docs-i18n-update                 # add new msgids / prune obsolete
# edit docs/locales/<lang>/LC_MESSAGES/<Doc>.po (fill msgstr)
make docs-i18n                        # check coverage (target: USER_GUIDE >= 80%)
make docs-check
```

Only user-facing pages are translated; the autodoc pages stay in English.

## Continuous integration

`.github/workflows/test.yml` runs `python3 scripts/check_docs.py` (job *Docs Consistency*).
`.github/workflows/docs.yml` builds all languages with `scripts/build_docs.sh` and
publishes to `geociencio/sec_interp_docs` (requires the `DOCS_DEPLOY_TOKEN` secret).
The local `.git/hooks/pre-push` also runs the docs gate before the CC gate.

## Troubleshooting

| Symptom | Cause / fix |
|---------|-------------|
| `WARNING: duplicate object description` / `toctree contains reference to nonexisting document` | Orphan `.rst` stubs for removed modules — delete them in `docs/source/`. `sphinx-apidoc --force` does not prune orphans. |
| API pages are empty / `No module named 'sec_interp'` | `conf.py` must add the **repository root's parent** to `sys.path`. |
| `sphinx-intl update` → `expected str ... not NoneType` | Missing `-d docs/locales` (handled by `translate_docs.py update`). |
| Phantom `code_walkthrough/code_walkthrough/` or `*.py.md` files | Obsidian creating targets for unresolved links; ignored via `.gitignore`. |
| Version drift in docs | Run `make docs-version` (or `build_docs.sh` syncs automatically). |
