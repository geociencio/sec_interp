# Release v3.0.1 - Extreme Stability & Global Reach

Highlights:
- **fix(gui)**: Eliminated all 22 signal leaks detected by `qgis-analyzer`, achieving a zero-leak status for superior UI stability.
- **feat(i18n)**: Expanded core support to 11 languages with the addition of **Hindi (HI)** and **Japanese (JA)**.
- **style**: Applied project-wide code formatting using `Black` and `Ruff`, improving maintainability and readability.
- **chore**: Optimized distribution package size by ~80% (down to 2.5MB) using advanced `.qgisignore` patterns.
- **test**: Stabilized integrated test suite in Docker environment with 386 tests passing.

This release focuses on industrial-grade reliability and broad accessibility, ensuring SecInterp remains the most robust geological interpretation tool for QGIS.
