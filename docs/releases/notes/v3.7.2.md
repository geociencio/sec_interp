# SecInterp v3.7.2: Qt6 / QGIS 4 Compatibility Patch

We are announcing the release of **SecInterp v3.7.2**, a patch that clears every Qt6 / QGIS 4 enum compatibility finding flagged by the QGIS plugin repository.

## 🔧 Key Changes

### Scoped Enum Migration (114 findings resolved)
QGIS 4.x enforces **scoped enums**. Flat references such as `Qgis.Critical`, `Qt.NoPen`, or `QgsWkbTypes.LineString` work under QGIS 3 / PyQt5 but are rejected by the plugin repository's Qt6 compatibility checker, which reported **114 Enum error findings** against the previous release.

This patch migrates all 114 usages to their fully scoped form across the plugin:

- `Qgis.Critical` → `Qgis.MessageLevel.Critical`
- `Qt.NoPen` / `Qt.NoBrush` → `Qt.PenStyle.NoPen` / `Qt.BrushStyle.NoBrush`
- `QgsWkbTypes.LineString` → `QgsWkbTypes.Type.LineString`
- `Qt.AlignLeft` / `Qt.AlignVCenter` → `Qt.AlignmentFlag.AlignLeft` / `Qt.AlignmentFlag.AlignVCenter`
- …and the equivalent scoped forms for every other flagged enum (`QMessageBox.StandardButton`, `Qgis.GeometryType`, `Qt.RenderHint`, `Qt.CursorShape`, `Qt.MouseButton`, `Qt.Key`, `QgsTask.Flag`, `Qgis.Filter`, `QgsVectorFileWriter.WriterError`, and more).

Test mocks were updated in lockstep so the full suite keeps validating against the scoped API.

### Qt6 Check Gate Wired Into CI
A `make qt6-check` gate now runs the exact `pyqgis4-checker` tool used by the QGIS plugin repository on upload. Future releases fail fast on any enum regression before packaging.

## 📈 Quality & Reliability
This release passes the full test suite via Docker, the **Cyclomatic Complexity ≤ 10** gate, and the security scan. The Qt6 compatibility checker reports **0 enum findings**.
