# SecInterp v3.11.0: Live Symbology & Legend Styling

**SecInterp v3.11.0** completes the interpretation workspace: a dedicated **Symbology** tab
styles the preview and the exported section live, a shared **per-unit editor** lets you
rename, recolor, reorder and hide units, and the legend itself becomes configurable.

## 🎨 Live Symbology (Settings → Symbology)

- A new **Symbology** tab styles the preview/export **live**: topography color mode, ramp/color
  and line width (moved here from the Section page), structures color/width, drillhole trace
  color/width/labels, and the default interpretation color.
- All styles are stored in the **project**, so a section keeps its look between sessions.

## 🧩 Per-Unit Editor (Settings → Symbology → Units)

- **Hide, recolor, rename and reorder** geological and drillhole units.
- Renames (aliases) and order are reflected in the preview legend **and** the exported image
  legend, and persist in the project. A **Reset unit styles** button clears the customization.

## 🧭 Legend Layout (Settings → Symbology → Legend)

- Choose the legend **position** (top/bottom × left/right), **font size** (6–16) and a
  **maximum number of items** (the rest are summarized as "+N more").
- The Symbology sections are **collapsible** and the tab scrolls, so a long list no longer
  forces the dialog to grow — the window height is bounded to your screen.

## 🧷 Legend Content

- The preview and exported legends show the **real symbology** (topography mode/color,
  structures color, drillhole trace color), separate **Geology units** from **Drillhole
  lithologies** under their own headers, and include the **interpretations**.

## 📈 Quality & Reliability

This release passes the full test suite, the **Cyclomatic Complexity ≤ 10** gate, the i18n
gate and the security scan. Docstring coverage is **100%**, `qgis-analyzer` reports
**0 issues**, and the layout was validated on real QGIS 4.2.1.
