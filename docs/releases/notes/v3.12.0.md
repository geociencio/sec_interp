# SecInterp v3.12.0: Section Selection & Interpretation Settings

**SecInterp v3.12.0** focuses on precision and structure: you can pick the exact section
line used for the profile, interpretation settings now live inside Settings, and the
business core is fully decoupled from QGIS.

## 🎯 Choose the exact section line

- The **Section Line** page now lists only **single-part lines with exactly two vertices**
  in a new `fid — label` selector.
- Pick the **label field** (`Auto` or any attribute) to make the feature list readable;
  the label only affects the combo text, not the sampled section.
- The selected `section_feature_id` is forwarded to topography, geology, structures,
  drillholes, level-of-detail and the async tasks, so switching the feature changes the
  sampled section.

## ⚙️ Interpretation settings, now part of Settings

- `InterpretationPage` is now the **Interpretation Settings** tab inside **Settings**
  (Default, Advanced, Symbology, Interpretation, Plugin Information).
- Configure the **storage source** (project-internal JSON or an external vector layer),
  **custom attributes** (name, type, default value) and **attribute inheritance** from
  geology layers and drillhole intervals.
- Existing projects, persisted keys and consumers keep working — no migration required.

## 🧠 A QGIS-agnostic core

- `core/` no longer imports `qgis.*` or `qgis.PyQt`: translations, settings and
  map-settings factories are injected through ports/adapters.
- The architecture allowlist is **empty**, and the core imports in a plain Python
  environment without QGIS.

## 🧩 Smaller, safer modules

- Controller **465 → 295** lines, geometry adapter **598 → 69**, preview layer factory
  **535 → 202**, 3D exporter **472 → 155**, preview renderer **438 → 335**.
- **No module exceeds 400 lines**; the CC ≤ 10 gate stays green.

## 📚 Documentation

- The User Guide ships with **22 refreshed screenshots** for the six-section sidebar,
  including the new **Symbology** and **Interpretation Settings** tabs.
- The Spanish User Guide catalog is complete.

## 📈 Quality & Reliability

The release passes the full unittest suite (**839 tests**), the **Cyclomatic Complexity
≤ 10** gate, the i18n gate, the security scan and the Qt6/QGIS 4 checker (0 findings).
The remaining analyzer findings are documented, non-blocking maintainability items.
