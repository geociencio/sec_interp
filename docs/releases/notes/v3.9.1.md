# SecInterp v3.9.1: Optional Smoothed Topography Profile

**SecInterp v3.9.1** lets you overlay a smoothed topographic profile on the section —
useful for stripping short-wavelength noise from a DEM before interpreting the geology,
while keeping the raw sampled data intact.

## 🧵 Smoothed Topography Profile

- A **Smooth** control in the preview **Controls** (with a **Window** in metres, 10–500,
  off by default) overlays a soft line on the topographic profile.
- On export, SecInterp additionally writes `topo_profile_smoothed.csv` and
  `profile_line_smoothed.<ext>` alongside the raw outputs; the raw data is never modified.
- Smoothing is a distance-window moving average (endpoints preserved), implemented in pure
  standard-library math.

## ⛰️ Geology on the Smoothed Profile

- With **Smooth** active, the geological profile (and its export) follow the **smoothed**
  topography using the same window, so the geology tracks the interpretation surface.
- Structures and drillholes keep their **raw** sampling, since they carry measured positions.
- Because the geology geometry now depends on it, changing Smooth regenerates the preview on
  the next **Preview**.
