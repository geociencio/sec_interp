# SecInterp v3.7.0: i18n Quality Gate & UX Improvements

We are pleased to announce the release of **SecInterp v3.7.0**. This update focuses on internationalization quality, a cleaner preview workspace, and leaner packaging.

## 🌐 Key Highlights

### i18n Quality Gate
We introduced a new Abstract Syntax Tree (AST) validation script (`verify_i18n_hygiene.py`) that systematically scans UI components for untranslated strings and enforces `self.tr()` wrapping with near-zero false positives. This gate is now part of the automated quality pipeline, preventing untranslated user-facing strings from slipping into future releases.

Additionally, we wrapped 9 previously untranslated error dialog titles (`Export Error`, `Preview Error`, `Geology Error`, `Drillhole Error`, and others) and the results `"ID:"` label in `self.dialog.tr()`, ensuring every user-facing message respects the active locale across all 13 supported languages.

### Collapsible Preview Controls
To give geologists more room for interpretation, the preview action buttons, Level-of-Detail controls, and layer checkboxes are now grouped into a collapsible `QgsCollapsibleGroupBox("Controls")`. The map canvas and status bar remain always visible, allowing you to collapse the controls and results panel to focus on the cross-section.

### Cleaner Packaging
The distributable ZIP now strictly excludes AI/agent tooling directories (`.codewhale`, `.continue`, `.deepseek`) and analyzer artifacts, guaranteeing a lean, plugin-only package for the QGIS repository.

## 📈 Quality & Reliability
This release passes **620+ automated tests** via Docker. All project functions comply with the **Cyclomatic Complexity ≤ 10** gate, and the security scan reports **0 vulnerabilities** with a **100/100** score.
