# SecInterp v3.12.1: Signal Idempotency & Portal Polish

**SecInterp v3.12.1** is a patch release focused on reliability and presentation. It
removes duplicate symbology signal connections, ships a 128×128 icon and expanded
plugin metadata, and leaves the plugin runtime free of development dependencies.

## 🔁 Symbology settings are now idempotent

- `SymbologyTab.connect_signals()` now disconnects its 15 internal `changed` links and
  the unit-reset button before reconnecting, without dropping external `changed`
  receivers.
- After repeated open/close cycles, a symbology change emits **one** preview refresh and
  the reset button performs **one** reset.
- Added real-Qt regression coverage: two `connect_signals()` cycles, one emission and one
  reset.

## 🎨 Icon and metadata

- The plugin now ships a **128×128 PNG** icon (`icon.png`) exported from the editable SVG
  master in `docs/source/images/sec_interp_icon.svg`.
- The `about` field now describes inputs, outputs, QGIS/Qt support, dependencies, license
  and source/documentation links for portal reviewers.
- A fresh package passes `qgis-manage validate --zip` with **zero warnings**.

## 🧰 Packaging and tooling

- `[project].dependencies` is empty: `qgis-plugin-analyzer`, `ai-context-core` and
  `sphinx-intl` are development-only. The plugin no longer pulls tooling into runtime.
- `qgis-manage 0.15.0` provides the artifact gate (`validate --zip`), the built-ZIP audit
  and permission normalization (`package --repo-check`), and portal security
  (`security --portal`).
- `qgis-plugin-analyzer 1.19.1` adds per-connection signal analysis; the remaining
  informational paths are upstream R3/R5/R6 false positives.

## ✅ Verification

- **844 tests OK** (2 real-Qt skipped); Docker suite exit 0.
- Ruff/format, Flake8 (portal scope), mypy, `check_docs`, i18n, Qt6 and security clean.
- Cyclomatic complexity gate PASS; plugin ZIP validated without warnings.
- QGIS 4.2.2 smoke test: open → preview → export PASS (10 drillholes, 9 geology
  segments, 9 structures, 430 topography points).

## 🔄 Upgrade

No project or data migration is required. Install the update from the QGIS Plugin
Manager or replace the plugin folder; existing projects, settings and interpretations
continue to work.

**Compatibility:** QGIS 3.28–4.x (Qt5/Qt6), Python 3.9+, GPL-2.0-or-later.
