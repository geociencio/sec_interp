# SecInterp v3.6.0: Next-Gen Stability & QGIS 4 Ready

We are proud to announce the release of **SecInterp v3.6.0**, a milestone focused entirely on extreme architectural stability and forward-compatibility with QGIS 4.x.

## 🚀 QGIS 4.x & Qt6 Full Compatibility
We have completely eradicated legacy UI threading segmentation faults. By adopting a robust asynchronous task anchoring strategy, the plugin now safely handles the differences between PyQt5 and PyQt6 (including the unhashable nature of `QgsTask` objects), ensuring your workflows remain uninterrupted across any QGIS version.

## 🛡️ Asynchronous Rendering Stability
Rapidly generating previews of complex geological intersections no longer risks freezing your canvas. We've introduced strict re-entry locks and deferred signal emission via `QTimer.singleShot` to safely pass heavy geodata from background threads directly to the main Qt event loop. Furthermore, C++ object lifecycles are now managed gracefully during teardowns to provide zero-crash guarantees.

## 🌍 Global i18n Coverage
SecInterp now features 100% internationalization coverage across its core exporting and profiling engines. We've fully synchronized all 13 supported locales (including French, German, Spanish, Japanese, and more), meaning the plugin speaks your language flawlessly.

## 📦 Modernized Deployment
For administrators and developers, our internal `qgis-manage` deployment CLI has been modernized to natively support multi-version profiles (both QGIS 3 and QGIS 4). The new automated module discovery guarantees seamless updates without missing dependencies.

## ✨ Sustained Quality
This release is backed by our strict zero-regression quality gate. All cyclomatic complexity is strictly maintained under CC <= 10, and the release is guarded by a 100% pass rate across our comprehensive 620-test suite (verified in Docker).

Thank you for choosing SecInterp for your industrial geological workflows!
