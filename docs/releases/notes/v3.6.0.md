# SecInterp v3.6.0: Next-Gen Stability, Spatial Optimization & QGIS 4 Ready

We are excited to announce the official release of **SecInterp v3.6.0**. This major release focuses on ensuring complete stability and compatibility for the new generation of QGIS (version 4.x and Qt6), alongside massive performance improvements for complex geological datasets.

## 🚀 Key Highlights

### Full QGIS 4 & Qt6 Compatibility
With QGIS 4 transitioning to Qt6, we've implemented the robust `qt6_compat` bridging layer. This completely resolves runtime crashes related to strict API typing, deprecated `QDialog` properties, and missing `Qt` enumerations (such as `QImage` formats and `QPainter` styles). SecInterp is now 100% stable across both QGIS 3.28 LTR and QGIS 4.x environments.

### ⚡ Extreme Spatial Performance
We have overhauled the interpretation attribute inheritance engine. By replacing pure Python distance checks with native C++ `QgsSpatialIndex` nearest-neighbor algorithms, point-in-polygon lookups now complete in a fraction of a second—even for projects containing tens of thousands of structural or drillhole data points. Furthermore, geological precision has been refined to calculate true perpendicular distances to line segments instead of isolated points.

### 🛡️ Iron-Clad Rendering Stability
To eradicate legacy segmentation faults and UI threading issues, SecInterp now features an advanced asynchronous task anchor. Combined with strict re-entry locks in the `PreviewRenderer` and deferred signal emission via `QTimer`, the plugin gracefully handles rapid user interactions, continuous map canvas panning, and heavy background calculations without freezing or crashing.

### 📦 Seamless Deployment
For enterprise users and developers, the internal deployment tool (`qgis-manage`) has been modernized to automatically detect and support multi-version profiles, seamlessly deploying to both `QGIS3` and `QGIS4` directories.

## 📈 Quality & Reliability
This release passes **620+ automated tests** via Docker. The entire codebase has been subjected to a strict quality gate, ensuring Cyclomatic Complexity remains ≤ 10 across all functions, guaranteeing long-term maintainability.
