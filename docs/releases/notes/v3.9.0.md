# SecInterp v3.9.0: DEM/Section Insights, CRS Safety & Adaptive Vertical Exaggeration

**SecInterp v3.9.0** turns the DEM and Section Line pages into a real interpretation
workspace: you now get band and profile statistics, a choice of profile styling, and an
automatic vertical exaggeration — backed by hardened coordinate-reference-system handling
that removes a class of freezes and silently wrong output.

## 🗺️ Section & DEM Insights

- **DEM band statistics**: the DEM/Raster page shows read-only **Minimum**, **Maximum**,
  **Mean** and **NoData** for the selected band. The sample is bounded, so large or remote
  rasters never block the UI.
- **Profile-vs-DEM statistics**: the Section Line page reports the section's **Minimum**,
  **Maximum**, **Mean** elevation and the number of samples at the DEM resolution, refreshed
  when the line, DEM or band changes.
- **Topographic profile color mode**: choose **Gradient** (with a color ramp such as
  *Spectral* or *Terrain*) or **Simple** (a single color) for the profile — a preview/export
  style only; the source layer is never modified.

## 🛡️ CRS Safety

- **Mixed-CRS warning**: an amber status appears when the section line, DEM and data layers
  use different coordinate reference systems.
- **Mislabelled-CRS block**: preview/export is **blocked** when a layer's declared CRS
  contradicts its coordinates (e.g. geographic data declared as projected), with a clear
  hint to fix it using *Assign Projection*.
- **Correct cross-CRS sampling**: topography, geology, structures and drillhole collars now
  reproject correctly, and a QGIS **freeze with mixed CRS** was fixed (densification is
  bounded and the sampling interval is computed in the section line's units).

## 📐 Adaptive Vertical Exaggeration

- An **Auto** toggle (default on) computes the vertical exaggeration from the profile aspect
  ratio and structural density, clamped to `0.5×–20×`. The manual spin remains as an
  override, and the current value is shown next to the toggle and in the results panel.

## 🔧 Stability & Housekeeping

- **No more scratch-layer leftovers**: closing the dialog no longer leaves temporary preview
  memory layers in the project (removed on OK/Save, Cancel/X and plugin unload).
- **Structural measurements** now sit on the topographic profile, and the Dip/Strike field
  selectors repopulate after choosing the structural layer.
